# 分析功能說明

繁體中文 | [English](./analytics.md) | [日本語](./analytics-ja.md)

Threads Analytics 儀表板中每張圖表與指標的完整說明，以及背後的計算規則。

> 時間序列圖表（觀看趨勢、整體成效、互動率趨勢、互動拆解、分享趨勢、觸及成長趨勢）都可切換**日／週／月**粒度，每張圖的選擇會各自記住。

## 總覽

| 區塊             | 顯示內容                                                                                                                                                                                                                    |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **摘要**         | 由這段時間的數字自動組成的幾句話：觀看與互動率的漲跌、發文量與一般貼文觸及、追蹤人數變化、追蹤者主要來自哪裡、最佳發文時段與最亮眼貼文。純規則產生，不會與下方數據卡矛盾。                                                  |
| **數據卡**       | 所選時段的總觀看、讚、回覆、轉發、引用、分享與互動率。每張卡片下方顯示相較於前一個等長時段的 `+/−%` 漲跌幅，並附上該指標在時段內的走勢小圖（日資料以 7 天平滑）。                                                           |
| **新貼文表現**   | 發文後才會出現：最近 48 小時內發布的每篇貼文，以最新一筆紀錄的觀看數，和你的一般貼文在同一時間點比較（以倍數顯示），並附上兩者的走勢小圖。要有至少 5 篇較早的貼文在那個時間點有紀錄，才算得出一般貼文，否則整張卡片不顯示。 |
| **最佳發文時段** | 以中位數觀看排名的前 2–3 個發文時段，並標示基於樣本數的可信度。                                                                                                                                                             |
| **觀看趨勢**     | 觀看數走勢，可切換日／週／月，並附上你的個人中位數基準線。                                                                                                                                                                  |
| **高曝光貼文**   | 觀看數超過中位數的貼文，依倍數排序（例如 `3.2× 中位數`）。                                                                                                                                                                  |

## 分析 — 成效分頁

分頁頂端的統計指標：**總觀看**、**日均觀看**、**互動率**、**分享率**。

| 圖表                | 顯示內容                                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **整體成效**        | 每日觀看數、發文量與單篇平均觀看數整合在同一條時間軸。                                                                                    |
| **單篇品質地圖**    | 以觸及（觀看數）vs 互動率定位每篇貼文的散點圖，點的大小代表分享數。分為四個象限：高觸及高互動、低觸及高互動、高觸及低互動、低觸及低互動。 |
| **觀看到行動漏斗**  | 從總觀看轉換到各行動類型（讚、回覆、轉發、引用、分享）的轉換率。                                                                          |
| **最佳發文時間**    | 各小時觀看中位數的長條圖，可篩選星期，並查看樣本數與可信度。                                                                              |
| **互動率趨勢**      | 每天發布的貼文各自的互動率，平滑線取最近七個有發文的日子。                                                                                |
| **最佳星期**        | 依星期比較中位數觀看、互動率與發文數。                                                                                                    |
| **格式 × 長度矩陣** | 以 2D 熱力圖比較各種內容格式與貼文長度組合相對於你的中位數觸及的表現。                                                                    |
| **互動類型佔比**    | 讚、回覆、轉發、引用、分享各佔總互動比例的圓餅圖。                                                                                        |
| **互動拆解趨勢**    | 讚、回覆、轉發、引用隨時間的堆疊趨勢圖。                                                                                                  |
| **觸及成長趨勢**    | 每篇貼文的中位數與平均觀看隨時間的變化——用來判斷帳號整體觸及是否在成長。                                                                  |
| **觀看數分布**      | 貼文落在各觀看區間的分布，以及各里程碑（1k、5k、1 萬…）的達成率。                                                                         |

## 分析 — 內容分頁

分頁頂端的統計指標：**發文穩定度**（有發文週數佔比）、**分享率**、**引用比例**（引用 ÷（引用 + 轉發））、**總貼文數**、**最長連續發文天數**、**目前連續發文天數**。

| 圖表                    | 顯示內容                                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------------------------ |
| **發文活動**            | 顯示每天發文數量的日曆熱力圖。                                                                         |
| **內容類型成效**        | 依媒體類型（文字、圖片、影片、輪播、音訊）比較中位數觀看、互動率與分享率。樣本數不足的類型會自動淡化。 |
| **貼文長度分析**        | 依字數區間比較中位數觀看。Tooltip 含平均值、P75、命中率與可信度。                                      |
| **發文頻率與成效**      | 分析每週發文量增加是否能提升觸及，或反而稀釋單篇品質。                                                 |
| **分享趨勢**            | 每日分享數的長期走勢。                                                                                 |
| **熱門關鍵字互動分析**  | 互動率最高的詞彙（至少出現 3 篇，不含 hashtag）。                                                      |
| **最佳發文頻率**        | 比較不同每週發文量下的單篇觸及與互動表現。                                                             |
| **內容類型 × 發文時段** | 根據中位數觀看找出每種格式的最佳發文時間。                                                             |
| **互動率最高**          | 以（讚 + 回覆 + 轉發 + 引用）÷ 觀看排名的高互動率貼文。                                                |
| **回覆率最高**          | 依回覆 ÷ 觀看排序，找出最能引發對話的貼文。                                                            |
| **分享率最高**          | 依分享 ÷ 觀看排序，找出最值得被收藏轉傳的貼文。                                                        |
| **發文間隔與成效**      | 依「距上一篇隔幾天」比較中位數觀看，判斷連續發文或休息幾天哪個表現較好。                               |
| **內容特徵對照**        | 有無連結、有無問句的貼文成效對照，用自己的資料回答「連結會不會傷觸及」。                               |

## 分析 — 受眾分頁

分頁頂端的統計指標：**追蹤人數**、**淨成長**（含 `+/−%`）、**平均每日增減**、**已累積天數**。

| 圖表             | 顯示內容                                                                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **追蹤人數變化** | 兩種檢視：**總覽**（追蹤人數折線）與**每日增減**（正負長條，變動最大的幾天會標出數值）。有發文的日子會在底部標記，tooltip 列出當天的貼文，方便追查是哪篇帶來漲幅。 |
| **追蹤者組成**   | 國家、城市、年齡、性別各一張分布圖，長條上的直線標示基準日位置，數字同時給人數與百分點變化。                                                                       |
| **組成變化趨勢** | 各分類佔比相對基準日的百分點變化折線，每個維度取變化最大的 5 項。組成移動極慢，改畫相對變化才看得出來。                                                            |

> Threads 只提供「當下」的粉絲數與人口統計，所以歷史紀錄從第一次同步開始，漏掉的日子無法回補。粉絲數每次同步都會更新，人口統計則每天抓一次，失敗的話，間隔至少六小時後的下一次同步會重試。人口統計需要帳號至少有 100 位粉絲。日期選單只列出有資料的日子。

> 貼文指標是累計值，每次同步時更新。儀表板不會保留發文後 24 或 48 小時等固定時間點的快照，想用相同的發文時長比較，需要自己另外記錄。

## 貼文頁面

貼文列表支援：

- **排序** — 依日期、觀看數或按讚數排序
- **搜尋** — 全文搜尋貼文內容
- **媒體類型篩選** — 只顯示當前時段內實際存在的類型

點選任一貼文後，右側面板顯示：觀看數、互動率、相對中位數倍數、觀看百分位，以及各行動類型的互動拆解長條圖。

### 成長曲線

面板裡的**成長曲線**顯示這篇貼文發布後前 7 天的觀看數累積，並以虛線對照你的一般貼文；下方列出發文後 1 小時、3 小時、6 小時、12 小時、24 小時、48 小時與 7 天的觀看數，以及在那個時間點是一般貼文的幾倍。這讓昨天和上個月的貼文能用同一個基準比較，不像上方相對中位數的數字會偏向較早發布的貼文。

- 成長資料由每次同步在貼文發布後 30 天內記錄：前 6 小時最密每 15 分鐘一筆、到 2 天每小時、到 7 天每 6 小時、之後每天一筆。從加入這項功能的版本才開始記錄，更早的貼文沒有成長資料。
- 兩筆紀錄之間的數值以內插推算；前後紀錄相隔太遠、無法推算的時間點顯示 `—`。每小時同步可以涵蓋所有時間點。
- **一般貼文**是你最近 60 篇有成長資料的貼文的中位數，不受所選時段影響，所以成長曲線和總覽的「新貼文表現」永遠一致。要有至少 5 篇貼文在某個時間點有紀錄，才會顯示一般貼文。

### 串文（多則貼文）

你在自己貼文底下接續發的回覆（第 2 則、第 3 則）會跟主貼文一起同步。只有從你自己的主貼文一路接下來的回覆才算串文，回覆別人的留言、以及在別人貼文底下的留言都不會納入。串文另外存放，不會被計入 dashboard 任何地方的貼文數。

- 多則貼文在列表與詳情標題會顯示 **N 則串文** 標籤。
- 詳情面板會顯示 **第 2 則保留率**：第 2 則觀看數佔第 1 則的比例，也就是有多少人往下讀。
- **串文** 區塊列出每一則的觀看數（以相對第 1 則的長條呈現）、按讚、回覆，以及與上一則相隔多久發出。
- **第 2 則類型** 依第 2 則的內容比較保留率：純連結、連結加說明、純文字。每個 chip 顯示該類型在目前時段的保留率中位數與篇數，不到 5 篇的類型不顯示中位數。
- CSV 匯出包含 `thread_parts` 與 `part2_retention_pct` 兩欄。

抓取串文需要 token 具備 `threads_read_replies` 權限。沒有這個權限的話，貼文仍會照常同步，只是會略過串文。
