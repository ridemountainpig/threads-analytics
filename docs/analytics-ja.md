# アナリティクスリファレンス

[繁體中文](./analytics-zh.md) | [English](./analytics.md) | 日本語

Threads Analytics ダッシュボードのすべてのチャートと指標、およびその背後にあるルールの説明です。

> 時系列チャート（ビューの推移、全体パフォーマンス、エンゲージメント率の推移、エンゲージメント内訳、シェアの推移、リーチ成長トレンド）は**日／週／月**の粒度を切り替えられ、選択はチャートごとに記憶されます。

## 概要

| セクション       | 表示内容                                                                                                                                                                                                                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **サマリー**     | 期間の数値から自動生成される数文：ビューとエンゲージメント率の増減、投稿数と典型的なリーチ、フォロワーの増減、フォロワーの主な地域、最適な時間帯、トップ投稿。ルールベースなので下のカードと矛盾しません。                                                                          |
| **統計カード**   | 選択期間の総ビュー、いいね、リプライ、リポスト、引用、シェア、エンゲージメント率。各カードは同じ長さの前期に対する `+/−%` の変化と、期間内の推移を示すスパークライン（日次は 7 日で平滑化）を表示します。                                                                           |
| **新しい投稿**   | 投稿後に表示：直近 48 時間以内の各投稿について、最新の記録時点のビュー数を同じ経過時間の通常の投稿と比較（倍率で表示）し、両者の推移を小さなグラフで示します。その経過時間に記録のある過去の投稿が 5 件以上ないと通常の投稿を算出できないため、それまではカード自体を表示しません。 |
| **最適投稿時間** | 中央値ビューでランク付けされた上位 2〜3 の投稿時間帯。サンプル数に基づく信頼度インジケータ付き。                                                                                                                                                                                    |
| **ビューの推移** | 日／週／月で切り替えられるビュー数の推移。個人の中央値ベースラインを併記します。                                                                                                                                                                                                    |
| **トップ投稿**   | 中央値を上回ったビュー数を持つ投稿を、その倍率（例: `3.2× 中央値`）でランク付け。                                                                                                                                                                                                   |

## アナリティクス — パフォーマンスタブ

タブ上部の統計指標: **総ビュー**、**1 日あたり平均ビュー**、**エンゲージメント率**、**シェア率**。

| チャート                          | 表示内容                                                                                                                                            |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **全体パフォーマンス**            | 日次ビュー、投稿数、投稿あたり平均ビューを 1 つのタイムラインに統合。                                                                               |
| **投稿品質マップ**                | リーチ（ビュー）vs エンゲージメント率で全投稿を散布図化。ドットサイズはシェア数。4 象限: ブレイクアウト、対話、ブロードキャスト、低パフォーマンス。 |
| **ビューからアクションへの漏斗**  | 総ビューから各アクション（いいね、リプライ、リポスト、引用、シェア）への変換率。                                                                    |
| **最適な投稿時間**                | 時間帯別の閲覧数の中央値を棒グラフで表示。曜日で絞り込み、投稿数と信頼度を確認できます。                                                            |
| **エンゲージメント率の推移**      | その日に公開した投稿のエンゲージメント率と、投稿のあった直近7日分の平滑線。                                                                         |
| **最適な曜日**                    | 曜日別の中央値ビュー、エンゲージメント率、投稿数。                                                                                                  |
| **フォーマット × 長さマトリクス** | コンテンツフォーマットと投稿長のすべての組み合わせを、中央値リーチと比較する 2 次元ヒートマップ。                                                   |
| **エンゲージメント種別の内訳**    | いいね、リプライ、リポスト、引用、シェアの割合を示す円グラフ。                                                                                      |
| **エンゲージメント内訳の推移**    | いいね、リプライ、リポスト、引用の積み上げチャート。                                                                                                |
| **リーチ成長トレンド**            | 投稿あたりの中央値・平均ビューの推移。アカウント全体のリーチが伸びているかを判断できます。                                                          |
| **ビュー数の分布**                | 投稿がどのビュー帯に分布しているかと、各マイルストーン（1k、5k、1 万…）の到達率。                                                                   |

## アナリティクス — コンテンツタブ

タブ上部の統計指標: **投稿の継続性**（少なくとも 1 件投稿した週の割合）、**シェア率**、**引用比率**（引用 ÷（引用 + リポスト））、**総投稿数**、**最長連続投稿日数**、**現在の連続投稿日数**。

| チャート                             | 表示内容                                                                                                                                       |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **投稿アクティビティ**               | 日ごとの投稿数を示すカレンダーヒートマップ。                                                                                                   |
| **コンテンツタイプ別パフォーマンス** | メディアタイプ（テキスト、画像、動画、カルーセル、音声）別の中央値ビュー、エンゲージメント率、シェア率。サンプル数が少ないカテゴリは淡色表示。 |
| **投稿の長さ分析**                   | 文字数バケット別の中央値ビュー。Tooltip には平均、P75、ヒット率、信頼度を含む。                                                                |
| **投稿頻度 vs パフォーマンス**       | 週あたりの投稿数を増やすと投稿あたりの平均ビューが上がるか下がるか。                                                                           |
| **シェアの推移**                     | 日次シェア数の長期推移。                                                                                                                       |
| **エンゲージメント上位キーワード**   | 平均エンゲージメント率が最も高い単語（ハッシュタグを除く、最低 3 投稿）。                                                                      |
| **最適な投稿頻度**                   | 週あたりの投稿量別の投稿あたりリーチとエンゲージメントを比較。                                                                                 |
| **時間帯別コンテンツタイプ**         | 中央値ビューに基づく各コンテンツフォーマットの最適投稿時間。                                                                                   |
| **エンゲージメント率トップ**         | （いいね + リプライ + リポスト + 引用）÷ ビューでランク付けされた高エンゲージメント投稿。                                                      |
| **リプライ率トップ**                 | リプライ ÷ ビューでランク付け — 最も対話を生んだ投稿。                                                                                         |
| **シェア率トップ**                   | シェア ÷ ビューでランク付け — 最も保存・転送された投稿。                                                                                       |
| **投稿間隔とパフォーマンス**         | 前回投稿から何日空けたかで中央値ビューを比較。連日投稿と間隔を空けるのとどちらが有効かが分かります。                                           |
| **コンテンツ特徴の比較**             | リンクの有無、質問の有無で投稿パフォーマンスを比較します。                                                                                     |

## アナリティクス — オーディエンスタブ

タブ上部の指標：**フォロワー数**、**純増減**（`+/−%` 付き）、**1 日あたり平均**、**記録日数**。

| チャート               | 表示内容                                                                                                                                                                                                        |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **フォロワー数の推移** | **全体**（フォロワー数の折れ線）と**前日比**（正負のバー。変動が特に大きい日には数値ラベル）の 2 つの表示。投稿した日は下端にマークされ、tooltip にその日の投稿が並ぶので、急増の原因となった投稿をたどれます。 |
| **フォロワー構成**     | 国・都市・年齢・性別それぞれの分布グラフ。バー上の線が基準日の位置を示し、人数とポイントの両方の変化を併記します。                                                                                              |
| **構成の推移**         | 各項目の構成比が基準日から何ポイント動いたかの折れ線。各項目で変化の大きい上位 5 件。構成は動きが遅いため、絶対値ではなく変化量で描いています。                                                                 |

> Threads が返すフォロワー数と属性データは「現在」の値だけなので、履歴は最初の同期から始まり、抜けた日をあとから埋めることはできません。フォロワー数は同期のたびに更新されます。属性データは1日1回取得し、失敗した場合は6時間以上あとの同期で再取得します。属性データにはフォロワー100人以上が必要です。日付の選択肢には、データのある日だけが表示されます。

> 投稿の指標は累計値です。同期では下の[伸び](#伸び)の記録と同じ間隔で読み直します。公開直後は最短 15 分ごと、公開 30 日目までに 1 日 1 回になり、それ以降は最後に読んだ値のままです。

## 投稿ページ

投稿リストは以下に対応:

- **並び替え** — 日付、ビュー、いいねで並び替え
- **検索** — 投稿コンテンツの全文検索
- **メディアタイプフィルタ** — 現在の期間に存在するタイプのみ表示

任意の投稿をクリックすると、ビュー、エンゲージメント率、中央値倍率、ビュー百分位、アクション別エンゲージメント内訳を含む詳細パネルが開きます。

### 伸び

詳細パネルの**伸び**セクションは、投稿後 7 日間のビュー数の積み上がりを通常の投稿（破線）と比べて表示し、投稿後 1 時間・3 時間・6 時間・12 時間・24 時間・48 時間・7 日時点のビュー数と、その時点で通常の投稿の何倍かを一覧にします。上の中央値比は古い投稿ほど有利になりますが、これなら昨日の投稿と先月の投稿を同じ基準で比べられます。

- 記録は投稿後 30 日間、同期ごとに行われます。最初の 6 時間は最短 15 分ごと、2 日目までは 1 時間ごと、7 日目までは 6 時間ごと、以降は 1 日 1 回です。この機能を追加したバージョンから記録が始まるため、それ以前の投稿には伸びのデータがありません。
- 2 つの記録の間の値は補間で求めます。前後の記録が離れすぎて推定できない時点は `—` と表示します。1 時間ごとの同期ならすべての時点をカバーできます。
- **通常の投稿**は、伸びのデータがある直近 60 件の投稿の中央値で、選択した期間には左右されません。そのため伸びセクションと概要の「新しい投稿」は常に一致します。ある時点に記録のある投稿が 5 件以上あると表示されます。

### スレッド（複数件の投稿）

自分の投稿の下に自分で続けた返信（2件目、3件目）は、元の投稿と一緒に同期されます。自分の元投稿から連なる返信だけがスレッドの続きとして扱われ、コメントへの返信や他アカウントの投稿への返信は含まれません。続きは別に保存され、ダッシュボードのどこでも投稿数には数えられません。

- 複数件の投稿は、リストと詳細ヘッダーに **N件のスレッド** バッジが表示されます。
- 詳細パネルには **2件目継続率** が表示されます。1件目に対する2件目のビュー比率、つまりどれだけの人が読み進めたかを示します。
- **スレッド** セクションには各件のビュー（1件目を基準にしたバー）、いいね、返信、前の件からの投稿間隔が並びます。
- **2件目のタイプ** は、2件目の中身（リンクのみ、リンク＋一言、テキストのみ）ごとに継続率を比べます。各チップには期間内のそのタイプの継続率中央値と件数が表示され、5件未満のタイプには中央値が出ません。
- CSV エクスポートには `thread_parts` と `part2_retention_pct` の列が含まれます。

続きの取得には `threads_read_replies` 権限を持つトークンが必要です。ない場合も投稿は通常どおり同期され、スレッドの続きだけがスキップされます。
